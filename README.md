#Sistema de Agendamento de Consultas-Especificações de Requisitos

##1.Visão Geral
Este documento especifica os requisitos funcionais e não funcionais do modulo de agendamento;

##2.Requisitos funcionais(RF)
- [ ] RF01 O paciente dev conseguir visualizar horarios disponiveis de cada médico.

- [ ] RF02: O sistema deve permitir o agendamento de consultas com confirmação via WhatsApp e
e-mail.

- [ ]RF03 O medico deve visualizar sua agenda diaria e semanal.

##3.Requisitos Não Funcionais(RNF)
-RNF01 (Desempenho): O tempo de resposta para busca de horarios nao deve exceder 2 segundos;

-RNF02(Segurança): Dados sensiveis de saude devem estar em conformidade com a LGPD.
